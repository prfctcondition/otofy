# Дизайн-система и принципы интерфейса Otofy (Zen Music)

Документ описывает визуальную философию, архитектуру интерфейса, принципы верстки, цветовую палитру и правила реализации компонентов приложения Otofy.

---

## 1. Философия и визуальная идентичность

Интерфейс Otofy построен на стыке двух направлений: <b>Liquid Glass (жидкое матовое стекло)</b> и <b>Скандинавский минимализм (Nordic Clean Design)</b>.

### Главные ориентиры:
- <b>Легкость и глубина</b>: интерфейс не должен ощущаться плоским или глухим. Пространство строится за счет полупрозрачных слоев с размытием фона (`backdrop-blur`), мягких внешних теней и тонких световых граней на границах блоков.
- <b>Контент на первом месте</b>: плеер, обложки альбомов, текст караоке и названия треков являются главными визуальными якорями. Элементы управления остаются сдержанными, аккуратными и не перегружают экран лишним визуальным шумом.
- <b>Двухполюсная эстетика тем</b>:
  - <b>Светлая тема (Light Theme)</b>: кристально чистое матовое стекло, мягкие дымчатые оттенки сланца, воздушные градиенты на фоне и глубокий контрастный цвет графита/сланца (`#0F172A`) для текста и акцентов.
  - <b>Темная тема (Dark Theme)</b>: чистый монохром Obsidian и OLED Pure Black (`#000000`), благородное стекло глубоких оттенков без дешевых цветных/неоновых подсветок, строгий белый контрастный текст и белые акценты.

## 2. Архитектура слоев и система стекла (Layering & Depth)

Интерфейс строится по трехуровневой системе глубины:

### Уровень 0: Базовый холст (Canvas)
- Фоновый слой всего окна приложения.
- В светлой теме: мягкий рассеянный градиент с холодными небесно-сланцевыми переливами (`#F8FAFC` -> `#EDF2F7`).
- В темной теме: глубокий чистый черный цвет (`#000000`), оптимизированный под OLED-дисплеи.

### Уровень 1: Парящие матовые панели (Grounded Floating Glass)
- Три основные функциональные колонки: левая библиотека (Your Library), центральный вьюпорт плейлиста и правая панель караоке-лирики.
- Характеристики панелей:
  - Закругление углов: `rounded-2xl` (16px) или `rounded-3xl` (24px).
  - Размытие: `backdrop-blur-xl` или `backdrop-blur-2xl`.
  - Заливка светлой темы: `rgba(255, 255, 255, 0.40)` до `rgba(255, 255, 255, 0.70)`.
  - Заливка темной темы: `rgba(6, 6, 8, 0.75)` до `rgba(14, 14, 18, 0.85)`.
  - Границы (Border Rim): тонкая полупрозрачная линия `border border-white/60` (в светлой теме) и `border border-white/10` (в темной теме), создающая эффект скошенного стеклянного края.
  - Тени: мягкие рассеянные тени `shadow-sm` или `shadow-md`, отделяющие панели от фонового градиента.

### Уровень 2: Навесные элементы и контролы (Elevated Controls & Floating Dock)
- Верхняя строка навигации и поиска, плавающий нижний док плеера, выпадающие контекстные меню и модальные окна.
- Повышенная плотность стекла: `bg-white/80` в светлой теме и `bg-[#121218]/95` в темной теме.
- Выраженные тени `shadow-xl` и `shadow-2xl` для четкого визуального парения над контентом.

## 3. Модульная трехколоночная компоновка

Рабочая область организована в виде модульной адаптивной сетки:

```
+-----------------------------------------------------------------------------+
|  Top Header: [< >] [Tabs]         [  Search Input  ]       [Tools] [- o x]  |
+-------------------+-------------------------------------+-------------------+
|                   |                                     |                   |
|   Left Sidebar    |            Center View              |   Right Sidebar   |
|   (Your Library)  |        (Playlist / My Wave)         | (Karaoke Lyrics)  |
|                   |                                     |                   |
|  - Category Chips |  - Hero Banner (Cover, Title, Meta) | - Track Header    |
|  - Search & Sort  |  - Action Bar (Play, Shuffle, ...)  | - Synced Lyrics   |
|  - Pinned Cards   |  - Tracklist Data Table             | - Provider Tag    |
|                   |                                     |                   |
+-------------------+-------------------------------------+-------------------+
|  Bottom Dock: [Track Info]    [Playback Controls & Progress]   [Extra Tools]|
+-----------------------------------------------------------------------------+
```

### 1. Верхний бар (Top Navigation Header)
- Навигация по истории: круглые кнопки «Назад» и «Вперед» (`< >`).
- Переключатели основных режимов: пилюли «Главная» (Home), «Обзор» (Compass) и «Моя Волна / Эквалайзер» (Wave/Sliders).
- Поисковая строка: центрированная вытянутая капсула с иконкой лупы и плейсхолдером `What do you want to play?`.
- Блок системных утилит справа: тумблер темы (Солнце/Луна), статус синхронизации Cloud, селектор языка, аватар профиля и кнопки окна (Свернуть, Развернуть, Закрыть).

### 2. Левая колонка: Библиотека (Your Library)
- Заголовок раздела с кнопками быстрого действия: импорт, экспорт, создание плейлиста, сворачивание панели.
- Фильтры в виде закругленных капсул (Pills): `Playlists`, `Artists`, `Albums`.
- Поиск внутри библиотеки и дропдаун сортировки (`Recents`).
- Карточки элементов библиотеки:
  - Обложка со скруглением `rounded-lg` или `rounded-xl`.
  - Название плейлиста/альбома жирным шрифтом.
  - Бейдж `Pinned` для закрепленных коллекций.
  - Подзаголовок с типом коллекции и автором.

### 3. Центральная область: Плейлист / Моя Волна (Main Viewport)
- <b>Hero-баннер коллекции</b>:
  - Крупная квадратная обложка с мягким свечением и тенью.
  - Тег типа (`PLAYLIST`, `ALBUM`, `ARTIST`).
  - Бейдж качества аудио: капсула с волной `Hi-Res Master Audio`.
  - Крупный заголовок (`text-4xl` / `text-5xl font-bold`).
  - Описание (например, исполнители, на основе которых сгенерирована Моя Волна).
  - Информационная строка: создатель, статус публичности, количество треков, общее время звучания.
- <b>Панель быстрых действий</b>:
  - Крупная круглая кнопка воспроизведения (темно-синий/черный круг с белым треугольником).
  - Кнопка быстрого микса, кнопка перемешивания (Shuffle), скачивание всех треков, кнопка дополнительных действий (`...`).
  - Локальный поиск по треклисту и переключатель порядка (`Custom order`).
- <b>Таблица треков (Tracklist Table)</b>:
  - Шапка: `#`, `TITLE`, `ALBUM`, `DATE ADDED`, иконка часов для длительности.
  - Строки треков: подсветка при наведении, номер/индикатор воспроизведения, обложка, название трека жирным шрифтом, имя автора, бейдж источника (`YT`, `SC`), альбом, дата добавления и точный хронометраж.

### 4. Правая колонка: Караоке-лирика (Lyrics Panel)
- Шапка панели: миниатюра трека, заголовок `Otofy Lyrics`, кнопка ручного поиска лирики и закрытия панели.
- Список строк:
  - Неактивные строки: сдержанный приглушенный цвет (`text-[#64748B]` в светлой теме, `text-white/40` в темной).
  - Активная строка: подсвечивается плавной стеклянной капсулой (`bg-black/5` или `bg-white/10`), шрифт увеличивается и становится высококонтрастным.
  - Пословная синхронизация (Syllable Sync): слова загораются синхронно с пением исполнителя.
- Футер панели: источник текста (`Powered by LRCLIB` / `LRC.RED`) и подсказка `Click line to seek`.

### 5. Нижний док: Непрерывный плеер (Persistent Player Dock)
- <b>Левый кластер (Now Playing)</b>: квадратная обложка трека со скруглением, название трека (с поддержкой прокрутки длинного текста), исполнитель, кнопка «В избранное» (Сердце) и кнопка офлайн-скачивания.
- <b>Центральный кластер (Playback Controls)</b>:
  - Кнопки: Shuffle, Предыдущий трек, крупная круглая кнопка Play/Pause, Следующий трек, Режим повтора (Repeat All / Repeat One / Off).
  - Прогресс-бар: тонкая полоса прокрутки со сглаженным ползунком-хэндлом, отображаемым при наведении, текущим временем слева (`0:58`) и длительностью трека справа (`2:46`).
- <b>Правый кластер (Tooling & Volume)</b>:
  - Кнопка открытия караоке-лирики (микрофон с синей подсветкой при включении).
  - Кнопка очереди воспроизведения.
  - Кнопка эквалайзера.
  - Иконка громкости и горизонтальный слайдер громкости.
  - Кнопка разворота в полноэкранный режим.

## 4. Цветовая система и токены (Palette Tokens)

### Акцентные и контрастные цвета
- <b>Основной акцент (Primary Accent)</b>:
  - Светлая тема: `#0F172A` (глубокий сланцевый индиго-черный).
  - Темная тема: `#FFFFFF` (чистый белый).
- <b>Инверсный текст акцента</b>:
  - Светлая тема: `#FFFFFF`.
  - Темная тема: `#000000`.
- <b>Активные кнопки и капсулы</b>:
  - Светлая тема: `bg-[#0F172A] text-white shadow-sm`.
  - Темная тема: `bg-white text-black shadow-[0_0_12px_rgba(255,255,255,0.25)]`.
- <b>Подсветка активных переключателей</b>:
  - Иконка активной лирики: акцентный лазурно-синий оттенок `#2563EB` / `#38BDF8` для моментального считывания статуса.

### Поверхности (Surfaces)
- <b>Фон приложения</b>:
  - Светлая тема: `#F8FAFC` -> `#FFFFFF`.
  - Темная тема: `#000000` (True OLED Black).
- <b>Стеклянные панели (Panels)</b>:
  - Светлая тема: `rgba(255, 255, 255, 0.45)` с `backdrop-blur-xl`.
  - Темная тема: `rgba(10, 10, 14, 0.75)` с `backdrop-blur-xl`.
- <b>Всплывающие окна и контекстные меню</b>:
  - Светлая тема: `rgba(255, 255, 255, 0.90)` с `border-black/10` и глубокой тенью.
  - Темная тема: `rgba(18, 18, 24, 0.95)` с `border-white/10` и черной тенью.

### Текст и иерархия шрифтов
- <b>Заголовки первого уровня (Hero & Page Titles)</b>:
  - Светлая тема: `#0F172A` (`text-slate-900`).
  - Темная тема: `#FFFFFF` (`text-white`).
- <b>Основной текст и названия песен</b>:
  - Светлая тема: `#1E293B` (`text-slate-800 font-semibold`).
  - Темная тема: `#F4F4F5` (`text-zinc-100 font-semibold`).
- <b>Вторичный текст и имена авторов</b>:
  - Светлая тема: `#475569` (`text-slate-600 font-medium`).
  - Темная тема: `rgba(255, 255, 255, 0.65)` (`text-white/65 font-medium`).
- <b>Служебный текст, даты, таймкоды</b>:
  - Светлая тема: `#64748B` (`text-slate-500 text-xs`).
  - Темная тема: `rgba(255, 255, 255, 0.40)` (`text-white/40 text-xs`).

## 5. Типографика

- <b>Основной шрифт</b>: современный гротеск (Inter, SF Pro Display, Segoe UI, system-ui).
- <b>Сетка начертаний</b>:
  - `font-bold` (700) / `font-extrabold` (800): крупные заголовки плейлистов, цифры таймкодов в Hero.
  - `font-semibold` (600): названия треков, активные вкладки, кнопки действий.
  - `font-medium` (500): имена авторов, названия альбомов, категории библиотеки.
  - `font-normal` (400): даты, служебные подсказки, технические метаданные.
- <b>Капсульные метки (Badges)</b>:
  - Размер: `text-[10px]` или `text-[11px]`.
  - Регистр: `uppercase` с увеличенным межбуквенным интервалом `tracking-wider` (например, `PLAYLIST`, `YT`, `SC`).

## 6. Микро-бейджи и индикаторы источников

Для быстрого распознавания контента используются компактные монохромные теги:
- <b>Источник потока (Stream Source)</b>:
  - `YT`: компактный скругленный бейдж с серой полупрозрачной обводкой для треков из YouTube Music.
  - `SC`: аналогичный бейдж для SoundCloud.
- <b>Статус синхронизации лирики в поиске</b>:
  - `(Synced, LRC.RED)`: пословная и посекундная точная караоке-синхронизация.
  - `(Synced, LRCLIB)`: построчная синхронизация.
  - `(Plain, LRCLIB)`: простой сплошной текст без временных меток.
- <b>Качество звука</b>:
  - Пилюля `Hi-Res Master Audio` с глифом волны для треков в максимальном битрейте.

## 7. Микро-взаимодействия и анимация (Motion & Feedback)

- <b>Плавность переходов</b>: все интерактивные элементы имеют плавный transition (`transition-all duration-200 ease-out`).
- <b>Наведение (Hover)</b>:
  - Карточки и строки треков слегка подсвечиваются слоем стекла (`hover:bg-black/[0.04]` в светлой теме, `hover:bg-white/[0.06]` в темной).
  - Иконки контролов плавно меняют прозрачность от `0.6` до `1.0`.
- <b>Нажатие (Active/Click)</b>:
  - Кнопки воспроизведения и капсулы поддерживают микро-сжатие при клике (`active:scale-95`).
- <b>Скролл в караоке</b>:
  - При смене строки контейнер караоке плавно центрирует поющуюся строчку с поведением `scroll-behavior: smooth`.
- <b>Слайдер прогресса воспроизведения</b>:
  - В обычном состоянии ползунок представляет собой тонкую линию высотой 3-4px.
  - При наведении курсора полоса слегка утолщается, и появляется круглый белый хэндл для точной перемотки.

## 8. Правила и запреты для разработчиков (Do's & Don'ts)

### Обязательно соблюдать (Do's):
- Использовать адаптивные утилиты `dark:` для каждого нового компонента.
- Сохранять радиусы скругления в едином стиле: `rounded-xl` (12px) для карточек и инпутов, `rounded-2xl` (16px) для секций, `rounded-full` для капсул и круглых кнопок.
- Использовать полупрозрачные границы `border-white/60` (светлая тема) и `border-white/10` (темная тема) на стеклянных контейнерах.
- Проверять контрастность текста: никогда не использовать светлый текст на светлом фоне или серый с низким контрастом в темной теме.

### Категорически запрещено (Don'ts):
- Запрещено использовать случайные ядовитые неоновые цвета (фиолетовый, ярко-зеленый, кислотно-розовый) в качестве системных акцентов. Системные акценты строго монохромны (`#0F172A` / `#FFFFFF`).
- Запрещено делать панели полностью глухими (opaque) без матового стекла `backdrop-blur`, так как это нарушает концепцию Liquid Glass.
- Запрещено использовать жесткие границы `border-black` толщиной более 1px.
- Запрещено ломать отзывчивость 3-колоночной компоновки на экранах ноутбуков: при сжатии окна панели должны корректно уменьшать ширину или прятать боковые колонки (лирику) по кнопке.
